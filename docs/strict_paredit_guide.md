# VS Code 网页版 Scheme / Strict Paredit 专属极速快捷键手册

> **设计哲学**：
> 1. **彻底废除 Leader 两阶段**：纯单发（One-Shot），按一下立刻生效，绝不搞 Vim 模态！
> 2. **左手大拇指锚定 Alt（Mac: Option / ⌥）**：100% 避开浏览器关闭标签（`Ctrl+W`）、网页后退（`Alt+←`）和 macOS 调度中心（`Ctrl+方向键`）。
> 3. **精准领域特化**：绑定统一附加 `editorLangId == 'scheme'` 判定，**在 `.scm` 文件中拥有绝对最高优先级覆盖权**，不干扰其他日常开发。

根据您指定的 **17 个物理键位**（`Alt + 1, 2, 3, Q, W, U, I, H, J, K, L` 以及 `Alt + Shift + U, I, H, J, K, L`），结合人类双手在主键区（Home Row）及数字区的自然伸展轨迹、左右手分工平衡，以及前面梳理的 **17 个 Scheme 结构化编辑与求值动作的日常使用频率（降序）**，为您重新进行了最科学、最具人机工学效能的键位矩阵分配。

### ⌨️ 键位分布与人体工学逻辑设计：

1. **最高频核心操作（45%）**：交给了右手食指/中指最舒服的 **`Alt + Shift + I`（向外扩选）** 以及左手极其顺手的 **`Ctrl + Enter`（发射求值）**。
2. **高频区间（20% ~ 25%）**：
* 包裹与吞吐（`W`, `U`, `H`）：左手掌管包裹（`W` / `U`），右手掌管树状结构的吞吐（`H` / `J` 映射左右移动）。


3. **中低频辅助操作（2% ~ 15%）**：
* 利用 `Alt + 1/2/3` 管理视窗与 REPL 基础流向。
* 利用 `Alt + Shift + 字母` 沉淀不常用的结构调整、对调与对齐操作。

## 🎯 17 个快捷键最终映射方案（按使用频率降序）

| 频级 / 占比 | 推荐快捷键 | 命令动作 | 心智助记符与手指分工逻辑 | 核心功能与效果 |
| --- | --- | --- | --- | --- |
| ⭐⭐⭐⭐⭐<br>

<br>(45%) | **`Alt + Shift + I`** | **向外扩选** (Expand) | **I**nward/Outward 纵向扩张（右手食指，极度舒适） | 自动严丝合缝选中当前 `(...)`，连按扩大一层括号。配合求值极度丝滑！ |
| ⭐⭐⭐⭐⭐<br>

<br>(45%) | **`Ctrl + Enter`** | **发射求值** (Eval REPL) | **左手不松 Ctrl，右手一拍回车** | 将当前选中的代码立即送入 Steel REPL 运行并吐出结果。 |
| ⭐⭐⭐⭐<br>

<br>(25%) | **`Alt + Shift + W`** | **圆括号包裹** (Wrap Parens) | **W**rap（左手无名指，主键区核心键） | `cards` $\rightarrow$ `(cards)`，单键把变量变成函数调用。 |
| ⭐⭐⭐⭐<br>

<br>(25%) | **`Alt + Shift + U`** | **方括号包裹** (Wrap Square) | **U**niform brackets（左手中指，上方延伸） | `x 10` $\rightarrow$ `[x 10]`，写 `let*` 局部变量和 `cond` 必备。 |
| ⭐⭐⭐⭐<br>

<br>(20%) | **`Alt + Shift + H`** | **向右吞噬** (Slurp) | **H**orizontal Expand（右手食指左侧，向右吸入） | `(a b) c` $\rightarrow$ `(a b c)`，右括号向右跨越一个元素。 |
| ⭐⭐⭐⭐<br>

<br>(20%) | **`Alt + Shift + J`** | **向左吐出** (Barf) | **J**etison 喷射抛弃（右手食指，向左收缩） | `(a b c)` $\rightarrow$ `(a b) c`，右括号向左收缩，踢出末尾项。 |
| ⭐⭐⭐⭐<br>

<br>(15%) | **`Alt + Shift + K`** | **向内收缩** (Contract) | **K**runch 收缩（右手中指，与 I 呼应） | 与 `Alt+Shift+I` 呼应，扩选过头随时往回收一级。 |
| ⭐⭐⭐<br>

<br>(10%) | **`Alt + 3`** | **选中顶级函数** (Defun) | 数字区 `3`（左手开局，定点直达） | 无论光标藏在函数内部多深，一键选中最外层整个 `(define ...)`。 |
| ⭐⭐⭐<br>

<br>(10%) | **`Alt + Shift + L`** | **脱壳解包** (Splice) | **L**ayer strip 剥离外壳（右手无名指） | `(let () (expr))` $\rightarrow$ `(expr)`，打碎外层括号提取内部代码。 |
| ⭐⭐⭐<br>

<br>(10%) | **`Alt + 1`** | **大步前进** (Forward) | 数字区 `1`（左手极限位） | 光标直接跨过右侧整组完整 S 表达式或参数。 |
| ⭐⭐⭐<br>

<br>(10%) | **`Alt + 2`** | **大步后退** (Backward) | 数字区 `2`（左手食指） | 光标直接跨过左侧整组完整 S 表达式或参数。 |
| ⭐⭐<br>

<br>(5%) | **`Alt + Q`** | **深度钻入** (Down) | **Q**uick dive（左手小指，左上角盲打起点） | 光标直接跳进当前括号内部最左侧第一个参数前。 |
| ⭐⭐<br>

<br>(5%) | **`Alt + W`** | **向上跳出** (Up) | **W**ay out（左手无名指上排） | 光标跳到当前外层括号左侧前置位。 |
| ⭐⭐<br>

<br>(5%) | **`Alt + U`** | **向后整块删除** (Kill Sexp) | **U**nload（左手中指上排） | 删掉光标右侧的一整组完整子表达式（不破括号）。 |
| ⭐⭐<br>

<br>(5%) | **`Alt + I`** | **智能格式排版** (Indent) | **I**ndent（右手食指上排，一键对齐） | 一键重新按 Lisp 缩进规范对齐当前 S 表达式代码块。 |
| ⭐<br>

<br>(2%) | **`Alt + H`** | **相邻参数对调** (Transpose) | **H**andle swap（右手食指基准位） | `(equal? a b)` $\rightarrow$ `(equal? b a)`，两项位置瞬间互换。 |
| ⭐<br>

<br>(2%) | **`Alt + J`** | **列表切分** (Split) | **J**oint cut（右手食指切分） | `(a b | c d)` $$\rightarro$ `(a b) (c d)`，从光标处把列表切成两半。 |
