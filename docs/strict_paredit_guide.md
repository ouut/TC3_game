# VS Code 网页版 Scheme / Strict Paredit 专属极速快捷键手册

> **设计哲学**：
> 1. **彻底废除 Leader 两阶段**：纯单发（One-Shot），按一下立刻生效，绝不搞 Vim 模态！
> 2. **左手大拇指锚定 Alt（Mac: Option / ⌥）**：100% 避开浏览器关闭标签（`Ctrl+W`）、网页后退（`Alt+←`）和 macOS 调度中心（`Ctrl+方向键`）。
> 3. **精准领域特化**：绑定统一附加 `editorLangId == 'scheme'` 判定，**在 `.scm` 文件中拥有绝对最高优先级覆盖权**，不干扰其他日常开发。

---

## 键盘符号对照说明 (Win / Linux vs macOS)

* **`Alt`** $\rightarrow$ **`Option (⌥)`**
* **`Enter`** $\rightarrow$ **`Return (↩)`**
* **`Backspace`** $\rightarrow$ **`Delete (⌫)`**

```
                         【左手大拇指锚定 Alt / Option】
         Q   W (包)  E (顶)  R       T (换)  Y       U (出)  I (收)  O (扩)  P
         A   S (脱)  D (钻)  F (跳前) G       H       J (吐)  K (吸)  L
         Z   X       C       V       B (跳后) N       M       [ (方包)
```

## 一、 快捷键全景图（按 Scheme 日常使用频率严格降序）

## 二、 肌肉记忆实战练习题（单发直按版）

请打开练习文件（如 `scripts/test_paredit.scm`），**纯单手直按触发**：

---

### 练习 1：极速扩选与发射求值（`Alt + O` $\rightarrow$ `Alt + Enter`）
**目标**：光标停在数字 `2` 处，0.5 秒内将 `(+ 1 2)` 送入 REPL 计算出结果 `3`。
```scheme
(+ 1 2)
```
* **操作步骤**：
  1. 按一下 **`Alt + O`**（Mac: **`⌥ + O`**）：编辑器高亮 `(+ 1 2)`！
  2. 左手按住 `Alt`（`⌥`）不松，右手直接敲 **`Enter`**（`Return`）！
  3. 右侧 REPL 瞬间吐出 `=> 3`。

---

### 练习 2：变量升格为函数调用 Wrap ()（`Alt + W`）
**目标**：把变量 `cards` 瞬间用括号包起来，变成 `(cards)`。
```scheme
;; 初始状态 (光标停在 cards 单词内部):
(define num-cards cards)

;; 目标期望状态:
(define num-cards (length cards))
```
* **操作步骤**：
  1. 光标放在 `cards` 内部。
  2. 按一下 **`Alt + W`**（Mac: **`⌥ + W`**）！
  3. `cards` 瞬间变成 `(cards)`，且光标停在最前面，直接敲入 `length ` 完成！

---

### 练习 3：构建局部绑定对 Wrap []（`Alt + [`）
**目标**：快速将键值对用方括号 `[]` 括起来。
```scheme
;; 初始状态 (选中或者光标在 len 10 处):
(let* (len 10)
  len)

;; 目标期望状态:
(let* ([len 10])
  len)
```
* **操作步骤**：
  1. 按 `Alt + O` 选中 `len 10`。
  2. 按一下 **`Alt + [`**（Mac: **`⌥ + [`**），瞬间包好！

---

### 练习 4：向右吞噬 Slurp（`Alt + K`）
**目标**：将落单的 `(list-last cards)` 吸入外层 `string-append` 括号内。
```scheme
;; 初始状态 (光标在 "当前: " 后面):
(string-append "当前: ") (list-last cards)

;; 目标期望状态:
(string-append "当前: " (list-last cards))
```
* **操作步骤**：
  1. 光标停在 `(string-append ...)` 内部。
  2. 按一下 **`Alt + K`**（Mac: **`⌥ + K`**），右括号瞬间把右侧元素吸进来！

---

### 练习 5：向左吐出 Barf（`Alt + J`）
**目标**：把错误包进加法里的 `"结束"` 踢出来。
```scheme
;; 初始状态 (光标在 (+ 10 20 ...) 内部):
(displayln (+ 10 20 "结束"))

;; 目标期望状态:
(displayln (+ 10 20) "结束")
```
* **操作步骤**：
  1. 光标停在 `(+ 10 20 "结束")` 括号内。
  2. 按一下 **`Alt + J`**（Mac: **`⌥ + J`**），`"结束"` 被踢出加法！

---

### 练习 6：脱壳解包 Splice（`Alt + S`）
**目标**：不需要 `let` 局部变量了，把内部代码直接提取出来。
```scheme
;; 初始状态 (光标停在 (engine:log ...) 上):
(let ()
  (engine:log "运行中"))

;; 目标期望状态:
(engine:log "运行中")
```
* **操作步骤**：
  1. 按 `Alt + O` 扩选到 `(let () ...)`。
  2. 按一下 **`Alt + S`**（Mac: **`⌥ + S`**），外壳瞬间粉碎剥除，只保留核心！

---

### 练习 7：整块安全删除 Kill（`Alt + Delete`）
**目标**：删掉无用的调试参数 `(debug-trace pid)`，绝不破坏括号。
```scheme
(do-move-card pid src dst (debug-trace pid) 'tail)
```
* **操作步骤**：
  1. 光标停在 `(debug-trace pid)` 头部。
  2. 按一下 **`Alt + Delete`**（Mac: **`⌥ + Delete`**），整组子表达式瞬间消失！
