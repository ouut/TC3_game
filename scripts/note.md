## 玩家操作 - 具体实现去掉括号
1. 移动卡牌	(m 0 1)	把第 0 行行尾的卡，送到第 1 行行尾（默认操作尾部，最常用的转运）
2. 送往行头	(mh 0 1)	把第 0 行尾部送进第 1 行头部（喂料给下游反应器）
3. 从头取走	(mhh 0 1)	把第 0 行头部卡移动到第 1 行头部
4. 快速清仓/整理	(c 0)	清理/出售第 0 行尾部卡牌（自动换成金币）
5. 一键转运全部	(ma 0 1)	把第 0 行所有产物一口气搬到第 1 行（流水线清仓神技）
6. 吃东西	(eat 0)	让村民吃掉第 0 行的食物
4. 要求自由，灵活，lisp方式无限扩展，而且需要玩家心智负担小



## 可视化、实体化的 Lisp 机器  - 游戏规则
1. 一切皆卡牌，Function 也是卡牌。 模仿lisp语法，函数卡后面接着参数卡，就自动计算产出的item放在后面，整行满了，就停下来，玩家移动到其他地方，会重新开始产出 
2. 桌面的宽高都可以消耗道具扩展
3. 行内任意连续序列触发，和lisp运行一致
4. Function卡牌 可以是一次性消耗品，消耗完毕就腾出位置。也可以是常驻卡牌，消耗后面的，自己不变，消耗完了，后面的自动向左对齐移动
Lisp 机器是瞬时求值的，但游戏需要时间维度（倒计时/进度条）。
当匹配到合法形式时，这一段卡牌进入“锁定/计时中”状态，抽走就中断反应，卡牌不损失。
5. 求值与放置位置：产物放在哪 - 原位替换 / 就地求值，最符合 Lisp）
6. 嵌套调用与括号/优先级怎么体现 - 只要检查到 函数卡 + 满足类型的参数序列，就锁定并开启进度倒计时，进度完成后规约
